## 内容范围

首版整理于 2026-11-26，共收录木作原分类 1,675 篇 Markdown、收纳原文 17 篇、业务模板 3 份。木作原文中含 14 张筑木应用卡及其入口，另有 1 份应用卡索引。实操部分有 5 份专题指南和 2 份筑木研究记录。

原分类、文件名、专业依据与验证状态保留。仓库内的资料互链可跨电脑打开。标为「本地参考资料」的条目需向工作室调取对应证据。客户工程文件、聊天记录、插件授权、密钥、索引缓存和大型目录附件保存在原处。知识库文本可离线读取和检索。另行获取的软件、厂家库及现场文件按具体任务接入。

## 怎样使用一条知识

1. 先找到对应分类和原文，保留条目的适用条件、例外及出处。
2. 用本项目的现场复测、设备和五金安装手册、确认过的工厂节点核实。遇到冲突，记录来源与差异，标明谁确认。
3. 把结果写进对应的报价、模型和图纸，记录版本、验收结果与待确认项。
4. 版本变更时更新原条目或对应实操指南，注明实测日期、适用条件和证据等级。教程、样件和厂试的验收分别记录。
