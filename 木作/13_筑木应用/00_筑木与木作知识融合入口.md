# 筑木 × 木作知识库：从规则到应用

更新：2026-11-03。首轮融合已建立14张应用卡。可用于查依据、安排练习、检查遗漏；不是已完成厂家验收的生产模板。

## 如何融合

原来的木作分类继续保留，作为材料、工艺、五金与安装知识的依据。新增应用卡把这些知识接到具体筑木对象和动作上；同一条原文只链接，不复制成第二份厂规。

关系是：**实际问题 → 应用卡 → 木作原文 + 工厂节点 + 筑木操作 + 型号资料 → 样件与验证记录**。

| 要解决的事 | 读取什么 | 应留下什么结果 |
|---|---|---|
| 确定柜体结构 | 厂家对应节点、库内结构和现场条件 | 板件/连接组成、材料、适用条件与冲突 |
| 快速建模和改尺寸 | 当前版本操作说明、所用模块 | 参数含义、父子关系、重算后的实体与清单 |
| 复用铰链、轨道、拉篮、衣杆、灯带 | 具体货号资料、模型与安装文件 | 型号、净空、方向、孔槽及计数的验证记录 |
| 房门、护墙、圆弧 | 节点、成型工艺与五金限制 | 完成面、开启、分缝、收口和样件 |
| 拆单对接 | 板件清单、标签、设备及工厂试件 | 差异、版本、负责确认的人与实物结果 |

业务仍先核报价及供货范围；教程的操作顺序不改变工作室业务顺序。原知识中的经验不能自动覆盖具体型号手册、现场尺寸或厂家已选节点；来源有冲突就并列留痕。

## 本轮新补的认识

- 官网有全局字段、配件转换、门板方向与机器对接的具体说明。旧版0/1语义并非都代表关/开；全局默认、修改已有对象、重算、云端同步要分别核。
- 可复用配件需连同型号与安装数据管理。统计进报表和自动开孔是两项能力，不能互相替代。
- 组框门要区分成品总成、开料构件和外协，条码还关联对象与订单身份。
- 圆弧需按实际材料/成型路线学习。原库的免漆拼接经验不能替代所有薄饰面成型资料。
- 预览卡住可进一步查是否已有报表及对应看板；机器生产验收则要看实际孔槽试件。本轮没有解决加载问题或完成试加工。

详细出处都放在相应卡内；参数值只在有来源、适用条件和验证状态时使用。

## 已纠正的五种容易混用

| 内容 | 本次处理 |
|---|---|
| 通用3/5/9毫米背板 vs 厂图12/14/18毫米选项 | 分开记录，通用列举不否定厂家18毫米 |
| 平板门2→约2.5毫米经验 vs 护墙3毫米缝 vs 5毫米插槽 | 门缝、槽宽、插片厚度分别建字段 |
| 旧全局表jccs名称 vs 专页槽深余量 | 标明文档年份和语义差别，不当最终深度 |
| 免漆圆弧无法无痕的经验概括 | 限定拼接/饰面/成型路线，不推广到所有产品 |
| 11月1日拉篮未放置 vs 11月2日已原点放置 | 采用较新记录；仍未装进柜内和验证孔位 |

## 怎样持续积累

每轮选一个具体问题，先检索现有卡；有同主题就补充新证据、边界或实测，不另堆一篇同义摘要。新增内容至少带：来源及日期、适用版本/材料/型号、当前学到了什么、没验证什么、关联知识条目。

看过目录、读过正文、看过视频、生成样件、修改重算、清单核对、工厂试件分别记录。一次读教程不能标成实操完成，某一步成功不能替代整套验收。

下一轮优先：
1. ZM-011：核v2报表看板适用性，区分未生成与未显示。
2. ZM-004：只选一种已有配件，补齐货号及安装资料，再安排独立样柜验证。
3. ZM-002/ZM-003：比较分格、门宽、盖值和扣尺，不直接改项目柜。
4. ZM-008/ZM-009：选择一套厂库护墙或圆弧节点，补完整剖面及材料路线。

默认资料研究在后台进行；需要软件实操时另用独立练习文件。本入口不是已启动的定时任务，不保证聊天结束后自动持续执行。

## 如何检索和更新

从应用卡正文、知识分类和来源编号检索。仓库提供 Markdown 正文和《知识卡索引.json》，索引以仓库根目录为路径基准。标为本地参考的资料可按标题或来源编号向工作室调取。

修改卡片时同步检查索引、来源和验证状态。本版可以离线文本检索。
