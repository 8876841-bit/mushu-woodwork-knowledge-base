# 收纳知识库 · 总览与导读

> 一份关于「住宅居住 / 收纳 / 颜值配色」的系统化知识库，由 G:\收纳 下的三本书、设计手册、L104 精细化指引与 PPT 模板资料，以及木属木艺「住商知识库」（逯薇三本书的颜值/功能/内核维度）去重、提炼、整理而成。现与木作知识库并排组成「全屋定制」专业内容。

## 一、这是什么

本知识库把散落在多份资料中的居住与收纳知识，提炼成 **580 条原子化知识点**（另补颜值配色、灯光吊顶飘窗、住商内核 3 个文件），按「方法论 → 空间 → 柜体系统 → 尺寸标准 → 交付标准 → 颜值配色」的逻辑组织成 17 个 Markdown 文件。每一条知识点都是自包含的（单独看也能懂），并标注了来源与页码，方便溯源。

**数据最值钱**：所有尺寸（mm/cm/㎡）、比例、数量、星级配置均已原样保留，可直接用于设计参考。

## 二、怎么用

按你的问题类型，从对应文件入手：

| 我想知道… | 去看 |
|---|---|
| 收纳的底层逻辑、通用原则、动线、布局方法 | `01-收纳方法论与核心原则` |
| 某个空间的收纳怎么做（玄关/客厅/餐厅/厨房/卧室/儿童房/卫浴/阳台） | `02` ~ `09` |
| 某类柜子怎么设计（玄关柜/橱柜/衣柜/浴室柜/餐边柜/超薄柜…） | `10-柜体设计与收纳系统` |
| 具体尺寸、人体工学数据 | `11-尺寸标准与人机工学` |
| 精装修交付的星级配置、标准 | `12-精装修交付与星级标准` |
| 配色、风格搭配、软装装饰 | `14-颜值配色与软装搭配` |
| 灯光、吊顶收口、飘窗改造 | `15-灯光·吊顶·飘窗` |
| 住商内核、家的情绪 | `16-住商内核与家的情绪` |
| 某个知识点出自哪本书/哪份资料 | `13-来源索引` |

三种常用检索入口：
1. **按空间**：玄关 → 02，客厅 → 03，餐厅 → 04，厨房 → 05，卧室 → 06，儿童房 → 07，卫浴 → 08，阳台 → 09。
2. **按柜体**：所有柜体集中在 10，含模块配置、材料、施工图要点。
3. **按数字**：找尺寸、星级、容积占比 → 11、12（内含对照表）。

## 五、整理说明

- 原始资料共 2574 个文件（含 982 页书籍转录、599 张图纸图片、PDF、PPT）。
- 三本书的逐页转录与知识点已存在于 `G:\收纳\_工作\`，本知识库在其基础上做了**跨来源去重**（同一知识点来自书/手册/PPT 的合并为一条、来源并列）。
- 去重原则：只合并真正重复的内容，保留所有独特信息与全部尺寸数据。
- 颜值配色、灯光吊顶飘窗、住商内核等维度已由「住商知识库」补入（14–16 文件），与收纳功能维度合并为本库的「居住/收纳/颜值」完整版。
