# 换电脑接手木作项目

在 GitHub 登录有权限的账号，从仓库的 **Code** 菜单选择 **Download ZIP**，解压到所选的工作盘。已经用 Git 管理资料时可克隆私有仓库，之后用拉取更新版本。希望后续回传新经验时用 Git 管理本地副本。

需要按关键词查资料时，打开 [离线检索与收录说明](../检索与收录说明.md)。

## 给另一台电脑的第一条任务

> 先读这份知识库的 README.md 和 AGENTS.md，再读当前客户项目的交接记录。先列项目正在使用的原始与定稿文件、已确认事实、待确认项和下一步。涉及报价、材料、五金、尺寸、收口、筑木及下单时，查相应条目并注明来源。所有待确认的数据保留状态，变更前核对关联模型、图纸与报价。把生成结果放到项目工作盘。

## 各文件各有归处

- GitHub 放可复用的专业知识、工作规则、检查表与经验。
- 客户的模型、报价、实测、现场照片、沟通和中间版由项目工作盘管理。使用前先核对当前原始文件和最终工作版。
- 加工和下单前，单独打开现场资料、厂家库和具体五金手册核验。记录 SketchUp、CAD、筑木版本与授权、厂库版本、样柜、报价及最后一次通过的验收。
- Codex 与 Claude Code 都可读取这些文件。给当前执行端提供明确的项目路径，保持单一写入者，交接写到项目记录并附真实产物。
