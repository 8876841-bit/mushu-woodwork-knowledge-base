# 小空间木作落地与售后复盘

整理自工作室早期案例的可复用问题。保留处理思路和复核条件；使用当前项目的尺寸、照片和设备说明判断是否适用。

| 环节 | 可复用的核对方式 |
| --- | --- |
| 紧凑空间的柜体整合 | 先列跨空间的取放动作、柜门开启面和摆放需求，再核通行、可达范围、柜体净空和相邻设备。给复合柜按使用动作划分区域。 |
| 柜体与室内开口 | 先明确开口是否经项目确认、基层与饰面如何收头，再核采光借用、隐私、柜体厚度和开启方向。墙体性质与能否开口要经现场及相关专业确认。 |
| 洗烘设备振动 | 从调平、支脚、设备制造商要求、设备与柜体接触、地面和管线逐项排查。记录空载与工作工况及处理后表现。隔振措施要兼顾设备稳定、散热和检修条件。 |
| 卫浴柜台面 | 按使用需求和项目选材，核靠水处、接缝、封边、开孔、积水清洁和触感。对样品或节点先做验证，再确认成品维护方式。 |

查资料可从 [收纳导读](../收纳/00-总览与导读.md)、[卫浴收纳](../收纳/08-卫浴收纳.md)、[阳台与家政](../收纳/09-阳台与家政收纳.md) 和 [安装交付](../木作/08_安装交付/) 开始。
