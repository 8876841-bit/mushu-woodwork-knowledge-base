# 筑木／筑巢公开教程：具体操作学习记录

研究日期：2026-10-30。执行端：Codex 子代理，公开网页检索与阅读；没有登录用户账号，没有操作本机筑木／SketchUp，没有上传客户模型或订单。

**适用版本未实测。** 以下记录的是能打开的原作者网页中的操作说明，不能据此宣称已掌握本机安装版，也不能将教程工艺、示例尺寸、库中默认五金或开槽参数视作木属木艺的厂规。本文研究软件操作，不提供下单工艺结论；涉及实际生产仍须核对木作知识库、合作工厂与具体五金资料。

## 2. BOX 到柜体框架：已读到明确动作

原作者：[vol.01替换柜体框架](https://sketchuppro.cn/4563)，2025-08-29，图文正文已打开。

1. 选中已经建立的 BOX。
2. 点右下角框架图标，替换成柜体框架；作者也给出直接输入 `201`、`202` 等代码的方式。
3. 对需要转成封板的 BOX，选中后用右下角封板图标。文章也给了转板件代码例子，但其中重复出现同一编号，本文不补猜其含义。

学习所得：BOX 是可替换的占位对象，框架、封板用不同入口。代码对应何种结构必须看当前库预览和实际参数，不能凭编号推断侧包顶底、踢脚或背板工艺。

## 3. 添加模块：快速设计与拾取内空

原作者：[vol.01添加模块组件](https://sketchuppro.cn/4565)，2025-08-29，图文正文已打开。

| 目标 | 原作者给出的具体做法 |
|---|---|
| 加层板 | 点“快速设计”图标，或使用作者配置的 `Alt+K`；将光标放到竖向板件上，再按工具提示添加 |
| 加中立板 | 激活快速设计后选择中立板，再把光标放到横向板件上 |
| 精确放板 | 添加过程中在右下角数值输入区输入数值 |
| 加抽屉、门、衣杆等 | 点“拾取内空”，或使用作者配置的 `Alt+S`；拾取目标空间，再点模块图标 |

正文给出的模块代码示例是衣杆 `789`、灯带 `601`、普通对开门 `11`。这里仅记录作者示例，尚未验证本机库是否存在、是否同义。模块依赖后台参数模型，不能以插入成功代替尺寸和五金核对。

## 4. 空间划分：内空均分与门板均分不同

原作者：[三门柜如何均分柜门](https://sketchuppro.cn/3208)，2025-02-08，图文正文已打开。

作者示例先建立框架，再通过快速设计放中立板：输入 `/3` 得到的是内空均分；希望三扇门等宽时，示例使用 `18|1:1:1|18` 放分隔，再拾取内空，通过 `10` 或 `01` 加门。

这里的 `18` 是该示例条件，不是本项目确认板厚。能学到的是“要先确定均分对象”：分净空、分门宽可能需要不同位置补偿，不能把一条示例公式直接用于全部板厚、盖值与门缝。

另一个[空间划分专题页](https://sketchuppro.cn/5715)可以打开，但可读内容主要是视频标题、日期和播放器模板，没有足以复现的文字步骤；本次不声称已学会其完整交互。

## 5. 参数编辑：有明确的应用步骤

原作者：[参数被限制时如何修改](https://sketchuppro.cn/4353)，2025-08-25，图文正文已打开。

作者以柜宽输入受限为例给出两条操作路径：

1. 双击“宽度”字段，弹出输入面板；输入目标值后点“应用多选”。
2. 或者输入后先点“确定”，再到编辑参数面板底部点“应用”。

后台修改库参数是另一种方法，本文没有执行。作者用 2700 演示输入；这只证明软件输入方法，**不表示任何 2700 毫米柜体或板件已满足工厂生产条件**。实际修改前应确认当前选择范围，尤其“应用多选”可能影响多个对象。

补充原作者：[盖踢脚抽屉抽盒过矮的处理](https://sketchuppro.cn/4365)，2025-08-25，正文已打开。作者对“2抽屉（有前侧板）”建议启用自动调节抽盒；对其当时的“7托底抽（有前侧板）”则提示库组件可能需要后台修正，初学者可通过编辑参数调整。这里只学习到不同组件的自动规则会不同，不能把当时的组件问题认定为本机当前版本仍存在。

## 6. 模块落在柜外：先检查层级

原作者：[拾取内空添加的模型为何在柜外](https://sketchuppro.cn/4344)，2025-08-25，图文正文已打开。

作者提醒初学者在板件、抽屉等未完成前先不要过早组合柜体。修改组合后的复杂模型时，可结合参数面板确认选中对象是柜体还是组合柜体，避免连续炸开破坏到板件层；必要时可用 SU 原位粘贴整理到正确层级。

这里不把“炸开”列为自动修复动作：本文没有接触模型，无法判断目标层级。以后练习时先用独立测试文件，保留组合前副本，再核对新增模块是否实际属于柜体。

## 8. 报表：更新流程与订单状态的具体动作

原作者：[更新订单、更新报表流程建议](https://sketchuppro.cn/3576)，2025-03-17，图文正文已打开。

作者的操作链为：先看订单上次下单时间 → 点订单号 → 更新报表 → 运行检测／生成步骤 → 核对创建成功提示 → 返回订单列表 → 刷新“所有项目” → 再检查时间是否更新。原文该步骤写作“智能检测生成报价”，与文章“报表”标题不同，本文保留这一用词差异，不擅自确认本机按钮名称。

原作者：[看完报表如何返回订单](https://sketchuppro.cn/4464)，2025-08-31，正文已打开。返回时点“项目”“所有项目”或“我的项目”；作者提醒“订单完成”是改变状态，可能让订单无法继续修改，并介绍有权限账号取消完成的处理方式。

**本次没有生成任何报表。** 尚未核实工厂报表字段、板件汇总、五金统计、封边扣减、纹理方向、导出格式、条码与 CNC 对接。不能仅凭“检测通过”或“报表生成成功”宣称可直接生产。
