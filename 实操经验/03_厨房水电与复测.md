# 厨房水电与现场复测

依据为工作室厨房水电流程、点位回归与图纸复核经验，以及 [测量与绘图](../木作/07_测量与绘图/) 和 [安装交付](../木作/08_安装交付/)。水电图版式继续按项目确认，厂商设备型号与现场位置是工程依据。

1. 先核设计师平面和原模型、现场量尺与墙面关系、设备型号及安装说明。在平面上明确会影响插座、给排水、燃气、排烟和灯位的柜体与电器。套装电器的接口分别核查。
2. 每个点列用途、编号、物理墙面、坐标、完成地面标高、尺寸起点、单位、要连的设备及确认状态。优先选现场可识别的同面完成墙角，注明左、右及量到中心的位置。前后墙与转折墙分开尺寸链。
3. 审批注时按页读全标记，先确认叉、问号和箭头含义。已确定迁移位置的点撤销旧位，保留其他点。新位置欠缺坐标时记录目标面和待确认项，在沟通稿上表达，原施工数据保留版次。
4. 修改时同步更新模型、点位尺寸与清单、整体图、墙面分图和位置小图。复测前后先比差异，再核该变化对柜体外形、背板、收口、五金、开口与报价的影响。
5. 核对点位总数、编号、位置、墙面、标高、尺寸基准和单位。重开模型，并逐页检查打印尺寸下的清晰度、遮挡、尺寸链和柜体关系。现场和设备厂家未确认的项目在交付说明中单列。

当厂家安装手册中有具体深度、开孔、安全距离或维修通道时，按对应型号的图文核查。图上数据的自动比对用于核差异，现场条件和图面表达仍需目视及人工确认。
