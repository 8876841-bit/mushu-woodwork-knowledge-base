# 筑木、SketchUp 与下单核验

结合 2026-11-03 筑木应用卡、11 月柜体深化和独立五金核对复盘整理。先读 [筑木应用卡](../木作/13_筑木应用/00_筑木与木作知识融合入口.md) 和 [下单核对模板](../风格手册/下单核对模板.md)。

## 先将报价、柜号与实体对齐

保留原模型，确定当前工作副本。核对报价部位、柜号和原模型对象。用相符的筑木样件核对柜体层级、门型、开合与连接关系，分开记录厂家节点、通用经验和项目已确认值。

## 给每一柜建板件与配件箱单

| 项目 | 核对内容 |
| --- | --- |
| 板件 | 归属柜号和总成、数量、实测尺寸、材质、可见面、封边、孔槽 |
| 抽屉 | 左右轨成副核用量，检查是否需锁扣或连接件，核抽盒净深、安装扣尺、载荷、孔位、行程及邻门干涉 |
| 门板 | 门型、铰链与底座、盖值、门缝、开启方向、收口干涉 |
| 挂衣及功能件 | 衣杆和端座、拉篮与附件，按具体型号核尺寸、方向、可用净空和固定方式 |
| 照明 | 灯带、型材、驱动、开关、出线与检修方式，逐项核供货归属 |

每行记录依据、数量、供货方和选型状态。在 SketchUp 中保留可编辑配件实例，放在正确柜号和总成下，保存能看清实际装配关系的场景，重开交付副本核对。展示配件注明用途。货号待定时填功能需求和冲突尺寸。只核过板件的成果用「板件沟通稿，五金未核」。

## 把验证做完再移动到下一阶段

- 更换参数要分别核全局默认、当前对象、原生重算以及同步后的结果。
- 先检查样柜完整装配，再对照板件清单、五金统计和实际孔槽。标明条码对应的订单、柜号、总成、部件及版本。
- 保留现场开合与安装剖面核对。由相应工厂验证加工、开槽、开孔、试件、兼容设备与报表。遇到未完成的报表或厂试，保留待验证状态。
- 材料与连接件另有 [铝型材知识](../木作/02_材料体系/铝型材/)。条件有差异时按选中型号和连接方式核算。
