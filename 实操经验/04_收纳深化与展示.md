# 整屋收纳深化与展示

依据为工作室多房间收纳深化和展示复盘。先查 [收纳导读](../收纳/00-总览与导读.md)、[柜体与收纳系统](../收纳/10-柜体设计与收纳系统.md) 与 [尺寸及人机](../收纳/11-尺寸标准与人机工学.md)。

1. 从住户习惯、物品尺寸、频次和取放动作建立每空间的收纳需求。记录事件先后、使用人和站位，再核门扇、抽屉、通道和设备占位。
2. 先核设计师已确认外形和现场尺寸，再确定柜内分区。按模型或实测核可用宽、深、高，区分标称外包和实际可用内空。可编辑模型的板件、五金和支撑关系先验收。
3. 从同一模型版本固定白模机位，覆盖空间关系、正面取物与局部细节。不同页保持同一材质、光线和柜体结构。看家具外观和讲取放动作各选需要的角度。
4. 展示开合时以真实铰侧、手拉侧、行程、翻盖或抽屉数量为依据。只有闭合原图或功能需求时，可标出部位并列内部结构和开向待确认；已核实的结构可以用剖视表达，并说明隐藏的部件。
5. 先改工程依据，随后更新展示图和图注。对业主展示讲清「放什么、站哪里、怎么拿」。图纸尺寸、型号和数量回到模型、测量及厂家资料查证。
6. 交付前重开可编辑文件，查看改动页和关联图页，核对引线位置、页码、注释、文字、边界和可读性。保留对应的模型版本与验收记录。
