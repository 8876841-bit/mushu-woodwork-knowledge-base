# 报价与版本核对

依据来自工作室业务规则、2026-11-25 报价复盘及 [报价体系](../风格手册/报价体系.md)。项目单价和供货定义按本次确认执行。

1. 以空间、部位和柜号分组，先把报价行与原模型一一对应。每行保留数量、单位、尺寸依据、材质、单价口径、供货方与状态。
2. 尺寸估算与价格确认分别记录。可分别注明「尺寸暂估、单价已确认」「待询价」等。暂估金额可按已确认口径并入当前合计，同时单列提示。总表同时展示待询价项及金额是否计入，避免把看板里的待询项误当成已报价。
3. 核查容易重复的界面。比如门扇框与安装框、独立围板与共用邻板、原结构板露面与额外饰面、抽面与抽盒和轨道。特殊结构、升级五金或材质差额单列，按本次报价口径判断归属。更换投影、展开或延米计价时处理旧行，避免双计。
4. 对照报价两版时，先确认部位、数量和尺寸是否一致，再匹配同一项目行。仅调整材质时，将差额归到受影响的条目。若数量、规则和单价同时变化，分别列原因。
5. 按绑定的计价规则逐行复算，金额精度按报价要求，随后核对分组、小计与总计。重开最终 Excel 复算确认，并核对导出 PDF 同页读数、项目范围及待询项目。保留版次差异与待确认事项。

报价前查 [成本与报价](../木作/09_供应链/成本与报价/)、[材料体系](../木作/02_材料体系/) 与 [五金配件](../木作/04_五金配件/)。历史价格和组合项使用记录要随同本次规格、单位和供货口径核实。
