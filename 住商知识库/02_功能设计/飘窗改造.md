# 飘窗改造（终极答疑）

> 来源：《小家，越住越大3》PART2（P147–189）｜主题：功能/飘窗

## 定位：飘窗梦碎——美图全靠摆拍

坐窗台"岁月静好"是照骗：台面太高脚不着地、后背够不着靠枕、腰椎无支撑、膝关节处直角小腿无法回勾。

## 一、飘窗三问

### Q1 开发商为啥做飘窗？
1. **显大**：视线能到多远，房间就显得多大，外凸飘窗让房间显大一圈
2. **不计面积**：空间高度 <**2.2m** 的飘窗不计入建筑面积（免费赠送）。例：3 卧室 3 飘窗约 3㎡，一线城市 4 万元/㎡ → 价值超 10 万元

### Q2 飘窗到底能不能砸？
- **假飘窗**：能砸（"偷面积"擦边球，一二线城市已陆续叫停）
- **真飘窗**：不能砸（底部悬空，砸掉透天；做法由规划部门审批，各城市细则不一）

### 5 种飘窗（除假飘窗外都不能砸）
| 类型 | 特征 |
|---|---|
| 1 假飘窗 | 非结构，可砸，逐渐叫停 |
| 2 标准飘窗 | **主流 80%**：窗台高约 45cm、台面深约 60cm |
| 3 落地飘窗 | 珠三角，落地但上部梁低压抑 |
| 4 低台飘窗 | 长三角个别城市，窗台 20–30cm，脚能着地，易改沙发/地台 |
| 5 超高飘窗 | 窗台 ≥80cm，建筑师"手抖"缺陷 |

## 二、改造①：飘窗改软座（人体工学）

**坐姿轻松关键算式：椅背 A + 座面 B + 座高 C = 110–120cm**（适用于大部分休闲椅，买家具也可参考）。

坐姿 4 要点：靠背（倾角 110°）、座面（软硬适中微后倾防滑）、座高（过高脚不着地）、座深（过深腘窝受压腿麻）。

**改造三步走**：
| 步 | 做法 | 尺寸 |
|---|---|---|
| 1 可靠靠背 | 三角木质板材＋软包，底边固定台面 | 高 45cm、底 15cm、软包 4cm |
| 2 舒适座面 | 前沿垫木条内倾＋海绵垫 | 木条 5cm、海绵 5cm |
| 3 地台脚踏 | 抬高踏面降低相对座高 | 相对高度 36cm；脚踏高约 18cm、宽 ≥30cm |

注意：座面内倾后前缘 >54cm 太高（脚不落地＋腘窝受压腿麻），故须抬脚踏。靠背影响窗帘 → 用百叶窗帘；**北方采暖区不适合**（冷凝水发霉）。

## 三、改造②：飘窗改书桌

**4 个关键值**：
| 参数 | 数值 |
|---|---|
| 桌面延伸容腿深度 | 25cm |
| 桌面距地高度 | 75cm |
| 抽屉底部距地 | 60cm |
| 窗帘留缝 | 15cm |

- 飘窗下方空间难利用（抽屉拉不出、搁板成死角）→ 干脆封死不用
- **低配版**：旧书桌锯掉后两条腿（锯掉＝桌腿高−窗台高），桌脚贴"家具助滑垫"滑动，用时拉出留容腿空间
- **高配版**：按 4 数值量身定制，结合旁边柜子集成（大桌＋大书架，适合儿童房）
- 预留 3 个插座（侧板暗线）：台灯 / 电脑 / **电动关窗器**（遥控开关窗，免爬高）

## 四、改造③：飘窗改榻榻米

窗台与榻榻米连成一体显房间大；**飘窗宽 >2m** 时可作床榻一部分，省空间惊人。

### 典型问题：上翻盖收纳
- 拿取不便（压上席梦思床垫一个人打不开）
- 密不通风易发霉（南方黄梅天/回南天）
- 退化路径：收纳 → 收藏（被遗忘）→ **窖藏**（注定的结局）

### 对策：三七规划法
| 分区 | 比例 | 做法 |
|---|---|---|
| 通风区 | 内侧 30% | 空置不储物；床箱侧壁开洞透气；外侧柜装迷你排气扇定期开启 |
| 储物区 | 外侧 70% | 用**滚轮深箱**替代上翻盖（可深 90cm+），外拉不受床垫妨碍 |
