# 儿童房设计（小房间大童年）

> 来源：《小家，越住越大2》第2章（P042–081）｜主题：功能/成长

## 定位：儿童房是家里最"不可能一劳永逸"的空间

- 关键在**成长属性**：孩子 9 年变化堪比蝌蚪变青蛙
- 双重原则：忠于孩子**当下的意愿** + 关注**未来的需求**
- 儿童房是动态的，不是静态的 → 设计**不一步到位，为未来留白**
- 让**孩子参与设计**（6 岁孩子已有主意、想象力、表现力）

**需求金字塔**（自下而上）：①睡眠隐私 → ②学习玩耍 → ③成长领地

## 成长阶段与尺寸变化

| 年龄 | 特征 | 身高 | 肩宽 | 凳高 | 桌高 |
|---|---|---|---|---|---|
| 6 岁 | 幼升小，培养适应力 | 115cm | 28cm | 27cm | 49cm |
| 8 岁 | 同龄社交，躲进自己房间 | | | | |
| 10 岁 | 青春期（男孩略晚），课业加重 | | | | |
| 12 岁 | 小升初，要求"平起平坐" | | | | |
| 14–15 岁 | 中二病叛逆期，二次发育 | 170cm | 45cm | 42cm | 73cm |

> 身高增长非线性，**10–13 岁猛地"蹿高"**。

## 挖掘空间潜力：门的魔法

小空间家具贴墙摆，**"延长"墙面 = 增加空间可能**，关键是**门的位置**。

门右移 600mm → 左侧墙形成凹位：

| 布局 | 书桌最长 | 柜体最长 | 总长度 |
|---|---|---|---|
| L 型（门在角部） | 1100mm | 1200mm | 2300mm |
| U 型（门移中） | 1700mm | 1700mm | 3400mm |

→ **提升近 1.5 倍**；中间地带由刀把形变完整方形，房间更开阔。

## 综合收纳柜（案例）

柜体：**长 1600 × 净深 500 × 高 2850mm，容量 2.28m³ ≈ 70 个登机箱**

分 4 区：上区空调 / 左区衣物 / 右区书籍 / 下区玩具，收纳孩子 80% 以上核心物品。

板材用**静电粉末喷涂饰面**（安全环保）。

## 三件核心物品的收纳

### ① 衣服 —— 挂衣杆可变

市售衣柜挂衣杆固定，对孩子不适用。方案：侧板左右各装波浪形**「任意撑」**，横杆架其上，**两档间隔 50mm**，按季节/衣长调节，孩子可自己调。

### ② 书 —— 层板深度要浅

- 书多 A5 大小，A4 最长边 ≤300mm；文件盒 310×250×90mm，书包 440×320×200mm
- **书架净深建议约 300mm，不超过 350mm**（深了前侧富余、易堆杂物）
- 柜体深 500mm − 层板深 350mm = **150mm** 不浪费 → 柜门内侧装透明亚克力挂盒（如冰箱门）
- 侧板打 **32mm 系统排孔**，层板按物品高度任意调节
- 门后透明盒作"书的贵宾席"放 1–2 本新书，激发阅读

### ③ 玩具 —— 桐木箱 + 黑板漆

大柜底层按尺寸定制 6 个独立活动**桐木玩具箱**（桐木厚 10mm、质轻），底装 4 个万向轮，头尾相连成"小火车"；正面刷**黑板漆**，分类内容由孩子自己用粉笔画（激发收纳兴趣）。

## 树屋（高低床）

孩子喜欢高低床，深层原因是其造型类似**树屋**（人类最初住所），满足安全感 + 领地感。

搭建（房间净高 2850mm、宽 2200mm）：

| 部件 | 做法 |
|---|---|
| 支撑结构 | 钢方通横跨房间搭"楼板"；边框/支脚 50×50 方钢管（壁厚 3mm），排架 25×25（壁厚 3mm），膨胀螺栓固定在混凝土墙 |
| 饰面 | 上下 18mm 多层木夹板 |
| 门窗墙 | 50×50 木龙骨 + 两侧 9mm 夹板 |
| 安全 | 靠近窗户装梯子 + 安全护栏（窗户另装铁艺防护网） |

- 下层不设固定家具，用轻小家具：**6–10 岁秘密基地**（布帘+玩具架）→ **10–15 岁兴趣空间**（书桌+电脑）
- 造价：树屋施工**仅 5000 块**（定制柜另计），半层面积 2m²

## 小房间"不压抑"三秘密

| 秘密 | 原理 | 做法 |
|---|---|---|
| 视线 | 第一眼视线抵达哪里，空间就延伸到哪里 | 窗户在右前方引导斜向视线；阁楼首层架空；大柜子放门后/光源对面 |
| 体量 | 体量感关键看**侧面** | 柜体嵌入 C 形空间隐藏侧面 → 体量"消失"，加长 50% 也不压抑 |
| 颜色 | 深色=重量感，暖色=前进色，冷色=后退色 | 树屋/大柜刷纯白，其他墙用浅灰蓝；素净空间+一点鲜艳配饰即可 |
