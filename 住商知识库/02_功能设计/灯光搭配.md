# 灯光搭配（瞬间改变气氛）

> 来源：《小家，越住越大2》第5章（P242–281）｜主题：功能/氛围

## 定位：灯光魅力，全在搭配

灯的本质是**光的容器**；灯光搭配＝根据空间功能和氛围，挑选不同角度和亮度的灯，形成适合的光环境（除照明外，还产生不同心境的场景氛围）。

## 一、灯光搭配三大误区

| 误区 | 内容 | 正确认知 |
|---|---|---|
| ① 重视"灯"忽视"光" | 买灯只关心风格/尺寸/功能/价格，以为"光＝买个灯泡" | 灯的根本价值在于"光" |
| ② 重视灯泡忽视色温 | 只看品牌/瓦数/LED/质量，不懂色温 | 色温描述光的冷暖程度 |
| ③ 重视主灯忽视搭配 | 只求"够亮、灯够多、瓦数够大" | 灯光魅力全在搭配（如衣服"白衬衫+牛仔裤"经典组合） |

## 二、色温

| 光源 | 色温 |
|---|---|
| 蜡烛光 | 1900K |
| 爱迪生 LED 灯泡 | 2700K |
| 黄光灯泡 / 住宅常用 | 3000K |
| 荧光灯管 / 医院 | 6000K |
| 高海拔蓝天 | 10000K |

- 色温越低光线越暖，越高越冷
- **住宅常用 3000K**（除厨卫外所有空间适用）；**厨房/卫生间用 4500K**
- 看灯泡包装盒数值，别信"暖黄光/冷白光"主观描述；可调色温 LED（3000–6000K）价格高、日常用不上，不必买
- 有说法：色温越低，人觉得时间流逝越慢

## 三、五大空间灯光配置

### 1 客厅灯（4 类）
| 灯 | 要点 |
|---|---|
| 主灯 | 别怕大！直径 **800mm 起步**（客厅 <10㎡ 除外）；20㎡ 客厅宜配直径 **1200mm 吊扇灯**（夏天比空调舒服省电） |
| 灯槽灯 | 小户型推荐做局部简洁灯槽；净高不足 **2700mm** 时，间接照明让天花板"飘"起来；造型务必简洁 |
| 读书灯 | 三方向光：射天花板（间接照明如月光）＋射书本（明亮宜人）＋射地面（平衡明暗、免疲劳） |
| 边几灯 | 沙发角落一盏台灯，如"原始部落火堆"，人自然围坐聊天 |

### 2 餐厅灯（三大要点）
| 要点 | 数值/做法 |
|---|---|
| 高度够低 | 首选吊灯，距桌面 **650mm**（过高光发散失去聚拢感、易炫光） |
| 位置居中 | 电位预留在**餐桌正上方**，不是天花板/餐厅中心（否则"歪"） |
| 半透光灯罩 | 无辅助光源时金属不透明罩 90% 光聚向下（餐桌极亮周边极暗），选布艺/玻璃半透光 |

餐边柜灯：餐边矮柜上方是照片墙绝佳位；通高入墙餐边柜在**吊柜底部内嵌 LED 灯**（照亮玻璃柜门餐具＋减轻厚重感）。

### 3 厨房灯（3 类）
| 灯 | 要点 |
|---|---|
| 集成吊顶灯 | 默认做法；但主灯居中、人操作背对主灯 → 操作全在阴影区 |
| 吊柜底灯 | **必不可少**，照亮操作细节防切手，暖白日光色显蔬菜色泽 |
| 水槽吊灯 | 低低亮亮一团光，摆脱洗碗孤单感 |

### 4 卧室灯（4 类）
| 灯 | 要点 |
|---|---|
| 无主灯 | 天花板中央不装主灯，由台灯/床头灯/装饰灯/灯槽提供局部照明（参考五星酒店）；床上无直射眼睛的光 |
| 摇臂床头灯 | 壁灯省空间、可旋转，床头灯＋阅读灯二合一；左右分开控制 |
| 感应小夜灯 | 感应亮起、几十秒自熄，防起夜刺眼；适合有小婴儿家庭 |
| 衣柜感应灯 | **最值得装，硬装水电阶段就预留电位** |

衣柜灯排序（效果/成本）：充电磁贴 LED（没留电位的补救，几天一充）＜ 衣杆自带灯（成熟简单）＜ **侧板内嵌灯（效果最好、价格最高）**。

### 5 卫浴灯（3 类）
| 灯 | 要点 |
|---|---|
| 镜箱灯 | 镜箱厚 **120–170mm**，传统镜前灯不适用；用**条状 LED 装在镜箱正面**（照脸无阴影，宜化妆），勿装上下灯带 |
| 小夜灯 | ①墙面嵌入型（防水）②插座型（几十元，占用插座）③暖风机带感应夜灯（一机两灯） |
| 阅读灯 | 顶灯装坐便器**前方 300mm**（正上方会投影头部阴影到书/手机） |
