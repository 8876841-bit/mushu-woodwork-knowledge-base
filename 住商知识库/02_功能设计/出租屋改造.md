# 出租屋改造（1000 元折腾出好日子）

> 来源：《小家，越住越大2》第6章（P284–319）｜主题：功能/低预算改造

## 定位：别人的房子，自己的日子

别等到买更大的房子时才想到享受生活；折腾出租屋的每个瞬间都是在为生活赋能。

## 一、改造三步走（住商冰山模型）

**顺序不能乱：①收纳改造 → ②功能改造 → ③颜值改造**

- 出租屋改造最常见误区是"头重脚轻"——下层基础（收纳、功能）不牢，上层颜值自然难维护
- 只刷墙、铺地毯、买家具、搭饰品的表面颜值改造，住一段时间会深陷收纳不足＋功能缺失的烦恼漩涡

## 二、①收纳改造：化零为整，立体集中

- 收纳不足是绝大多数出租屋的致命缺陷；年轻人物品从一箱涨到塞满一屋只需数月
- 分散买小收纳容器＝"塞满→买容器→又塞满→又买容器"死循环
- **集中收纳区三要诀：贴墙、全长、到顶（顶天立地）**

**不推荐的廉价容器**：开放式挂衣架（显乱）、塑料收纳箱（鲜艳花哨、拿取不便）、简易布制衣柜（挂多易倾斜）。

**租房替代方案（约 1000 元，可拆可复用）**：天花板装窗帘轨道（小空间用强力支撑杆）＋网店"顶天立地衣架"挂衣＋并排置物架（宜家勒伯格）＋素色大布帘遮挡杂物。

## 三、②功能改造

### 第一步：优化布局
- 把占空间的大件家具（床、沙发床）从窗前采光好位置腾出，让给书桌
- 床平放占地大 → **竖起来（翻转 90°）** 靠墙；床头板螺丝铆接可拆下反装
- 沙发床拆成钢支架＋垫子，塞进大床垫背后缝隙"封印"
- 腾出空间按功能分区：窗前工作区 A＋中部休闲区 B

### 第二步：灯光改造（最少投入、最大改变）
- 房东默认只有天花一盏白色吸顶灯＝惨白寡淡，拒绝乏味
- **无预留灯位的 DIY 吊灯套路**（沿用衣帽间加灯招）：网购便宜吊灯（¥63）留 3 米长电线 → 五金店加插头 → 拧带钩螺丝进木吊顶 → 电工绑带卡线 → 电线藏窗帘背后 → 接插线板
- **遥控灯泡**（¥30）：无开关也不弯腰，三挡调光
- 厨房走廊式无窗：吊柜底部粘 **40cm LED 感应柜底灯**（¥80）挥手即亮；水壶角落加带插座感应 LED 灯泡（¥45）

## 四、③颜值改造：从打造小角落开始

如拼大幅拼图先从一个角落入手；**第一个角落奠定空间颜值的基本风格**。

**休闲区低成本布置（案例）**：
| 物件 | 做法 | 花费 |
|---|---|---|
| 香薰炉＋扁柏精油 | 森林味道建立"这是我家"归属感 | ¥148 |
| 棉质大蒲团 | 直径 700mm，可坐可枕＋木托盘兼茶几 | ¥70 |
| 沙发盖巾当地毯 | 1700×2100mm，厚重可机洗 | ¥135 |
| 旧边桌换实木桌腿 | 螺丝刀半小时 DIY | ¥50 |

**布艺改造**：素色麻布窗帘换掉陈旧咖啡色窗帘（¥187，光线变明亮柔和）；门洞挂半帘（¥69，遮蔽＋私密）；旧地毯铺厨房走廊如花砖。

**旧物翻新与捡拾**：椅面用订书机换棉质包装袋布；小区垃圾箱捡松木条拼地垫、梯架挂绿萝；龟背竹水培绿三周、多肉"顺"、石头烛台——几乎全 ¥0。

## 五、清洁三法宝（改造前）

| 法宝 | 用途 |
|---|---|
| 碳化硅水砂纸 | 打磨洗脸台/厨房台面钢丝球都搞不定的污渍 |
| 除霉剂 | 瓷砖黑缝一夜变雪白；水龙头底部霉斑 |
| 浴室喷雾（日产） | 马桶/水龙头喷泡＋超细纤维巾擦至闪亮 |

吸尘器重灾区：**床垫和柜子顶部**，非地板墙角。
