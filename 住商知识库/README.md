# 住商知识库

木属木艺工作室的「居住 / 收纳 / 配色 / 户型」知识库，作为木作知识库的姊妹库。

## 来源

整理自逯薇的三本书（中信出版集团）：

| 书 | 主题 | 页数 |
|---|---|---|
| 《小家，越住越大2》 | 功能 / 收纳 | 184 |
| 《小家，越住越大3》 | 颜值 / 配色 | 381 |
| 《小家大变局》 | 户型布局 | 400 |

核心概念：**住商** = 把房子住成家的能力。住商体系 = 收纳（基础）+ 功能（基础）+ 颜值（上层）+ 爱（内核）。

## 使用方式

- 报价 / 设计 / 写内容时，按主题到对应分类查询知识点。
- 每条知识点保留读书笔记中的数据、尺寸及适用情形。用作量尺、选材或下单依据前，回到原书、现行标准和项目资料复核。
- 柜体相关同时查 [木作知识库](../木作/)；按空间查 [收纳专题](../收纳/00-总览与导读.md)。
