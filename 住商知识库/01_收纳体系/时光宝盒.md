# 时光宝盒（回忆收纳法）

> 来源：《小家，越住越大2》第7章（P322–351）｜主题：收纳/理念

## 定位：给舍不去的回忆一个安稳的家

主张减法生活，但**不主张丢弃一切**。完全极简、空无一物的家并非终点；一路上总有些物品让人不忍丢弃。

## 一、时光宝盒收纳法

### 做法
- 从 2007 年起，每年年初备一个新纸盒，贴上**年份标签**
- 这一年间，时不时把不忍丢弃的小东西存进去
- **一年一盒，不多不少、不大不小，刚刚好**

### 容器
宜家经典款收纳纸盒，尺寸 **260×160×150mm**（只比半张 A4 纸略大一点）。

### 原理
- 人类记忆研究中：潜意识把一切封存在脑海深处，犹如一个个抽屉；旧物是打开抽屉的**钥匙（Memory Key）**
- 时光宝盒＝"回忆的钥匙盒"——与其随手乱丢零星的钥匙，不如给它们一个安稳的家

### 小身材大容量
随机清点某一年度盒子：**55 件纸质物品＋19 件杂七杂八小玩意＝一盒 74 件小物**。

## 二、家庭仪式：和孩子一起存回忆

- **怀旧是人类的天性**（5 岁孩子也爱看自己小时候的东西）
- 孩子会主动拿小物请大人代存：海边贝壳、游乐场门票、坏掉的小玩具……
- 和孩子一起，把承载美好瞬间的小物**郑重放入宝盒**，是家庭日常生活中不可或缺的小仪式

## 三、藏品示例（什么值得存）

| 年份 | 藏品 |
|---|---|
| 2007 | 迷你香薰炉（嗅觉是记忆最隽永的） |
| 2008 | 快递单（父亲寄黄杏） |
| 2009 | 日本伊豆旅行塑料袋 |
| 2010 | 结婚那天穿的连衣裙 |
| 2011 | B 超单 / 年记卡片 |
| 2014 | 儿子生日蛋糕的镂空糖粉纸样 |
| 2016 | 首版签名本的内页 |

## 四、年记卡片

盒盖内侧放一张"**年记**"卡片，按日期记录当年大事（示例 2011 年记：1.8 婆婆手术成功…10.24 我怀孕了，共 10 条），年度主题如"交替与新生"——如同生命的年轮。

## 五、结语理念（住商内核）

- **面对乱："别崩，要接纳"**——乱是必然的，崩没必要
- **家，是人生缩影**：看家三阶段「看家是家 → 看家不是家 → 看家又是家」
- **烟火气 ≈ 生活臭**（隈研吾《十宅论》说法）：家有烟火气所以踏实熨帖，家有生活臭所以无法永保整洁
- 有点乱，是家最自然的样子；回到家里放松一点，不要苛责、放弃极致（Just Relax!）
- **接纳你的小家，等于接纳你自己；家是心的终极治愈所**
