# 住商体系（核心概念）

> 来源：逯薇《小家，越住越大》系列｜主题：总纲

## 什么是"住商"

**住商 = 把房子住成家的能力。**

> 房子 + 住商 = 家。

住商是可学习、可提升的能力——就像智商、情商、财商一样。

## 住商冰山模型（四要素）

```
        ┌──────────┐
        │   颜值    │  ← 上层（可见，最易被重视）
    ┌───┴────┬─────┴───┐
    │  收纳   │   功能   │  ← 基础（隐藏，最易被忽视）
    └────────┬─────────┘
         ┌───┴───┐
         │   爱   │  ← 内核
         └───────┘
```

| 层 | 要素 | 说明 |
|---|---|---|
| 上层 | 颜值 | 配色、搭配、风格（最易被重视，但最表面） |
| 基础 | 收纳 | 空间整理能力（基础之一） |
| 基础 | 功能 | 空间使用效率（基础之一） |
| 内核 | 爱 | 家人之间的情感联结（一切的根本） |

**核心结论**：改造或装修最常见的误区是"头重脚轻"——只做上层颜值，不触及下层的收纳和功能，下层基础不牢固，上层自然难维护。

## 通用方法论

### 改造 / 装修三步走（顺序不能乱）
1. **收纳改造** → 2. **功能改造** → 3. **颜值改造**

### 核心态度（结语）
- 面对家里的乱：**"别崩，要接纳"**——乱是必然的，崩没必要
- **家，是人生缩影**：看家三阶段「看家是家 → 看家不是家 → 看家又是家」
- 烟火气 ≈ 生活臭（隈研吾《十宅论》）：家有烟火气所以踏实熨帖，家有生活臭所以无法永保整洁
- 有点乱是家最自然的样子；回到家里放松，不要苛责、放弃极致（Just Relax!）
- **接纳你的小家，等于接纳你自己；家是心的终极治愈所**
