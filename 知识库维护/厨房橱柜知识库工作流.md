## 一、知识分类体系

```
01_厨房基础
  ├── 橱柜构成        # 地柜、吊柜、高柜、台面、五金基础
  ├── 基础装修        # 厨房空调、水电预留、墙体要求
  └── 电器规划        # 电器点位、电路预留

02_材料体系
  ├── 台面材料        # 石英石、岩板、人造石、不锈钢、原木
  ├── 施工工艺        # 台面安装、拼接、打磨
  └── 柜体材料        # 板材类型、封边、环保等级

03_功能设计
  ├── 尺寸与高度      # 台面高度、吊柜高度、人体工学
  ├── 动线规划        # 取洗切炒动线、U型/L型/一字型
  └── 收纳设计        # 抽屉分配、拉篮配置、转角利用

04_五金配件
  ├── 水盆与龙头      # 材质选择、安装方式、生产工艺
  ├── 拉篮与收纳件    # 调味拉篮、碗篮、转角拉篮
  └── 铰链与滑轨      # 品牌选择、阻尼类型、使用寿命

05_厨房电器
  ├── 烟机灶具        # 类型选择、安装尺寸、风量要求
  ├── 嵌入式电器      # 蒸箱、烤箱、洗碗机、冰箱
  └── 其他电器        # 消毒柜、微波炉、垃圾处理器

06_工艺体系
  ├── 标准柜工艺      # 柜体结构、连接方式、垫板垫条
  ├── 特殊柜工艺      # 水槽柜、转角柜、烟机柜、冰箱柜
  └── 细节收口        # 灯光、拉手、吊顶、分水器隐藏

07_测量与绘图
  ├── 现场测量        # 测量技巧、精确测量、管道排图
  ├── 图纸规范        # 现场手绘、CAD规范、标注标准
  └── 拍照存档        # 拍照要点、档案管理

08_安装交付
  ├── 水电交底        # 方案确定、必须有图纸、灯光点位
  └── 验收标准        # 安装检查项、常见问题、交付流程
```

## 三、层次定义

| 层次 | 定义 | 举例 |
|------|------|------|
| 事实层 | 具体数据、操作步骤、材料参数、行业标准 | 台面标准高度850mm，石英石厚度15mm |
| 规律层 | 反复成立的经验判断和模式 | 北方家家户户有分水器，必须做活动层板方便检修 |
| 原理层 | 解释"为什么"的底层机制 | 木材热胀冷缩，所以柜体与墙体之间必须留3-5mm缝隙 |
```
